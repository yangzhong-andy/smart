# 水滴飞扬 ERP 微信小程序

原生微信小程序工程，用于在手机端查看 TikTok Shop 订单。该目录独立于 Next.js 网页端，不改变 3001/3003 的数据库和页面结构。

## 已实现

- 使用现有 ERP 账号登录
- TikTok Shop 订单分页加载和下拉刷新
- 按订单号、店铺、订单状态筛选
- 运输超过 8 天预警
- 商品图片、SKU、数量、订单金额和订单来源
- 订单物流及收件信息详情

## 本地运行

1. 打开微信开发者工具。
2. 导入本目录 `miniprogram`。
3. AppID 已配置为 `wxc35b5669b6444f0a`。
4. 开发阶段关闭“校验合法域名、web-view、TLS 版本以及 HTTPS 证书”。

当前开发接口为 `http://149.88.87.208:3001`。正式发布前必须完成以下事项：

- 将 ERP 域名解析到当前服务器并启用有效 HTTPS 证书。
- 在微信公众平台配置该 HTTPS 域名为 request 合法域名。
- 更新 `config/env.js` 中的 `apiBaseUrl`。
- 完成小程序备案并提交版本审核。

小程序不需要、也不应包含 AppSecret。后续如接入微信一键登录，AppSecret 只保存在 ERP 服务端环境变量中。
