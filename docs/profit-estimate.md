# 跨平台价格选品与利润测算

本页 `/finance/profit-calculation` 是上架前的预测工具，不读取订单来改写已结算利润，也不生成财务流水。实际利润仍以系统各平台订单、结算和费用规则形成的 `/finance/profit` 等报表为准。

- 支持 TikTok Shop 巴西、Shopee 巴西、Mercado Livre 巴西。各平台的候选商品在 `ProfitSelectionItem` 中分开保存，可先手工记录，也可关联现有 `ProductVariant` SKU。测算选择候选商品时复制商品名、成本、重量、头程和目标售价，之后手工修改只影响本次测算。
- 历史 `ProfitCalculation` 保留原记录；新记录增加平台、候选商品关联和 `inputSnapshot.version=2` 的完整输入与结果。旧记录仍标记为旧版口径，不在迁移中重算。
- TikTok 巴西保留旧测算的 6% SFP 物流佣金，以及免佣无效时追加的 6% 平台佣金和 BRL 4/件。其他平台的佣金率、履约和尾程费用由操作者输入预测值，默认 0 **不表示官方免收**。海外仓费可按旧重量阶梯一键估算，所有平台都允许改写报价。
- `GMV = 折扣后售价 × 件数`；`预计结算 = GMV - 平台佣金/物流佣金 - 履约费 - 尾程费`。采购、头程、海外仓、达人佣金、税、开票、回款手续费和广告费再折算/扣除得到预计净利润。达人佣金计入利润成本，不冒充官方结算扣款。
- 广告 ROI 为 `GMV(CNY)/广告费(CNY)`；保本广告预算为扣广告前的可用利润（最低 0），保本 ROI 为 `GMV/保本广告预算`。旧版历史的 ROI 字段含义不同，不能直接混排比较。
- 页面上的 BRL/CNY 汇率默认从现有财务汇率接口获取；接口不可用时显示提示并允许手填。存档时由服务器重新计算，不能由前端提交净利润覆盖结果。
