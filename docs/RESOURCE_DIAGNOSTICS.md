# 内存事件诊断（默认关闭，按环境启用）

## 范围与原则

这是用于定位 2026-10-16 3001 内存异常的观测代码，不是内存问题修复。
不改业务算法、请求体/响应体、鉴权、数据库结构或账务；不触发同步、不自动重试、不重启进程。
2026-10-16 先完成本地验证，随后用户授权发布到 3001。正式发布只包含诊断及线上已有的供应商税务 SSO 基线，不包含未发布的工资改动；部署状态和启用情况须在发布后核验，不能据此声称原因已定位。

覆盖：TK 同步、TK webhook 接收及响应后的异步处理、TK 仓库费用核对、通用利润报表、Shopee 利润报表及推送恢复处理、美克多商品同步。

## 启用与撤销

只有 Node 服务环境变量 `ERP_RESOURCE_DIAGNOSTICS=1` 时才启用。默认关闭；关闭时不读取内存、不建立计时器、不输出诊断日志。
可选 `ERP_RESOURCE_DIAGNOSTICS_INTERVAL_MS`，默认 15000 毫秒，实际限制 5000—300000 毫秒。
不能将这些变量放入客户端 `NEXT_PUBLIC_*` 配置。

必须基于经过核对的生产代码，从干净 Git tag 走受管理发布流程，保留现有供应商税务 SSO；不夹带未发布工资功能，不引入数据库迁移或业务数据修改。若受管理流程执行迁移检查，须预先确认候选迁移全部已应用，没有待执行迁移。
启用/关闭都需要让对应 Node 进程重新读取环境，需提前说明短暂重启影响。3001 使用独立的服务环境配置启用，不影响 3003；发布后核对进程环境及真实诊断记录，不能只凭源码存在就认定正在采集。
撤销观测可移除启用变量后重启对应服务，或回滚至已核验的上一完整 release；不回滚数据库。

## 记录内容

日志前缀 `[ERP Resource]`，后面为单行 JSON：

- UTC ISO 时间（展示/对账时转北京时间）、PID、固定任务名、进程内生成的作用域 ID 和父 ID。
- `start`、`checkpoint`、`end`，以及每 15 秒一次的 `sample`。
- `rss`、`heapUsed`、`heapTotal`、`external`、`arrayBuffers`，单位 MiB。
- 耗时、HTTP 状态（不读取响应正文）、任务并发数量、阶段及白名单计数，如订单条数。
- 最多六个最早开始的活跃任务、采样延迟 `lagMs`、被限额省略的事件数。
- 每个作用域观测到的 RSS 峰值；它仅是采样/检查点捕获的峰值，不是精确峰值。

不记录 URL、查询参数、请求头、Cookie、令牌、订单/店铺 ID、客户资料、请求/响应正文或错误消息/堆栈。任务名、阶段、计数均有固定白名单，不能直接放入任意业务对象。

一个 Node 运行时共享一个采样器（独立 worker 可能各有一个，可按 PID 区分），计时器 `unref`，不阻止进程退出。
最多保留 128 个活跃作用域的少量元数据，不保存请求对象或历史快照。超过上限仍计入任务并发数，但不保证逐项展示或捕获其峰值。
每分钟最多输出 120 条任务事件（每个作用域生命周期可能因此不完整），额外保留固定频率心跳。没有无限制日志缓冲。
采样器在首次被观测任务后持续运行，即使没有活跃任务也记录基线；这便于区分任务结束后的内存留存。
诊断读内存/写日志/建立采样器失败不应影响业务结果。

## 如何解释

内存值是**整个 Node 进程的共享内存**，不能把两个检查点的差值直接算成某个请求独占的内存。
作用域 ID 用于串联异步调用；TK webhook 的接收结束后，其后台处理仍有独立作用域，不能因 HTTP 已返回就认为任务完成。
现有内部 HTTP 报表请求尚未携带诊断关联头，因此跨内部 HTTP 边界不能保证父子 ID 串联，应结合时间和并发数分析。

1. 若并发任务数持续升高、最早任务耗时增长，优先查请求堆积或下游卡顿。
2. 若 `heapUsed` 随特定阶段增长，优先查 JS 对象和全量数据处理；若 RSS 增长但 heap/external 不匹配，再查原生分配、线程、分配器留存等，不立即认定 JS 泄漏。
3. 任务结束后 RSS 不立即下降不一定是泄漏。需要重复周期、堆使用量和业务量共同判断。
4. `lagMs` 大表示采样受阻/调度延迟，不单独证明哪段代码卡住。
5. 没有活跃观测作用域时仍增长，说明还需扩展覆盖；本次不是所有请求的审计系统。
6. OOM 前可能来不及写结束事件；结合最后心跳、内核 OOM、定时任务日志分析。

不要为复现而重放攻击请求或重复触发生产同步，也不要在接近 OOM 时抓取可能耗费数 GB 的堆快照。
本次未改变 PM2 启动方式、内存阈值、公网端口、限流规则或依赖版本；这些属于独立修复范围。
